# Security

Do not include actual secrets, source snippets or confidential paths in public reports. Describe the rule, synthetic reproduction, expected behavior and affected version. Until a project-specific private reporting channel is configured, use your hosting provider's private vulnerability-reporting facility when available; do not post sensitive evidence publicly.

The scanner is local discovery and developer assistance, not a complete DLP boundary. Git hooks can be bypassed. Detection cannot prove credential validity or certify an unenumerated filesystem. Reports/catalogs reveal sensitive locations and need private permissions. Python extensions are trusted code and document parsing uses third-party libraries. Only load reviewed plugins and keep dependencies current.
